# WarungOS

Dashboard Management Warung Kampung - Next.js + Tailwind CSS + TypeScript

## Deploy di Vercel

1. Push repo ke GitHub
2. Buka [vercel.com](https://vercel.com) dan import repo
3. Vercel auto-detect Next.js, klik Deploy
4. Done!

## Development

```bash
npm install
npm run dev
```

## Fitur

- Input Omzet Harian + pembagian otomatis (70/15/10/5)
- Stok Barang + Alarm Restock
- Grafik Omzet 7 Hari
- Target Modal (10jt -> 20jt)
- Responsive Mobile + Desktop
- Data di localStorage
